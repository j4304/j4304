## 🚀 Currently Building
**[PEAKL](https://peakl.games)** is a free open-play management platform for pickleball clubs in the Philippines, which I designed, built, and launched solo in August 2026.
- 🏓 **470+ players** across club sessions, with **50+ live viewers** on the real-time match board every live session
- ⚖️ Custom **Swiss-MMR matchmaking**, automated session scheduling, and dynamic leaderboards
- 🛠️ TypeScript · Supabase · Drizzle ORM · PostgreSQL
- 🌱 Now expanding into a multi-tenant SaaS platform open to any club or community
